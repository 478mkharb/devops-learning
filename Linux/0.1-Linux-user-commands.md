# 🐧 Linux User & Group Management – Detailed Canvas

---

## 📌 1. User Management Commands

### 🔹 1.1 Rename User

**Command:**

```
usermod -l studentA student1
```

**Explanation:**
Changes username from `student1` to `studentA`

**Example Use Case:**

* Renaming users after onboarding policy change

---

### 🔹 1.2 Add User to Group (Overwrite Groups)

**Command:**

```
usermod -G devops user2
```

**Explanation:**
Adds user to `devops` group but removes existing groups

⚠️ Warning: Overwrites existing group memberships

---

### 🔹 1.3 Append User to Group (Safe Method)

**Command:**

```
sudo usermod -aG group01 user03
```

**Explanation:**
Adds `user03` to `group01` without removing existing groups

**DevOps Use Case:**

* Grant temporary access to deployment group

---

### 🔹 1.4 Lock User Account

**Command:**

```
usermod -L username
```

**Explanation:**
Locks user account (disables password login)

---

### 🔹 1.5 Lock User + Set Expiry

**Command:**

```
usermod -L -e YYYY-MM-DD username
```

**Explanation:**
Locks account and sets expiration date

**Example:**

```
usermod -L -e 2026-12-31 user1
```

---

### 🔹 1.6 Unlock User

**Command:**

```
usermod -U username
```

**Explanation:**
Unlocks previously locked account

---

## 📌 2. Group Management Commands

### 🔹 2.1 Add User to Group (Alternative)

**Command:**

```
sudo gpasswd -a Shaurya Xgroup
```

**Explanation:**
Adds user `Shaurya` to group `Xgroup`

---

### 🔹 2.2 Remove User from Group

**Command:**

```
gpasswd -d student1 admin
```

**Explanation:**
Removes `student1` from `admin` group

---

### 🔹 2.3 Create System Group

**Command:**

```
groupadd -r groupname
```

**Explanation:**
Creates a system group (low GID)

**Use Case:**

* Service accounts (nginx, docker, etc.)

---

### 🔹 2.4 Rename Group

**Command:**

```
groupmod -n newname oldname
```

**Explanation:**
Renames an existing group

---

## 📌 3. Password Aging & Security (chage)

### 🔹 3.1 View Password Aging Info

```
chage -l username
```

### 🔹 3.2 Set Password Expiry Days

```
chage -M 90 username
```

### 🔹 3.3 Set Minimum Days Between Password Change

```
chage -m 7 username
```

### 🔹 3.4 Set Warning Days Before Expiry

```
chage -W 10 username
```

### 🔹 3.5 Set Account Expiry Date

```
chage -E YYYY-MM-DD username
```

### 🔹 3.6 Force Password Change on Next Login

```
chage -d 0 username
```

---

## 📌 4. Key DevOps Notes 🔥

* Always use `-aG` with `usermod` to avoid breaking access
* Prefer `gpasswd` for scripting group membership
* Use `chage` for compliance (ISO, SOC2)
* Lock inactive users instead of deleting them
