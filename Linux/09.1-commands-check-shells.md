# 🐧 Linux Shell + tmux Master Canvas

---

# 🔑 WHAT IS A SHELL?

```
User → Shell → Kernel → Hardware
```

Shell = Command interpreter between user and OS

---

# 🧠 TYPES OF SHELLS

## 🔹 Common Shells

| Shell | Path          | Description          |
| ----- | ------------- | -------------------- |
| bash  | /bin/bash     | Default in Ubuntu    |
| sh    | /bin/sh       | POSIX shell          |
| dash  | /usr/bin/dash | Lightweight shell    |
| zsh   | /usr/bin/zsh  | Advanced interactive |
| rbash | /bin/rbash    | Restricted bash      |

---

# ⚙️ SHELL TYPES (INTERVIEW IMPORTANT)

## 1️⃣ Login Shell

* Started when user logs in
* Loads:

  * /etc/profile
  * ~/.profile

## 2️⃣ Non-Login Shell

* Open terminal inside session
* Loads:

  * ~/.bashrc

## 3️⃣ Interactive Shell

* User can type commands

## 4️⃣ Non-Interactive Shell

* Runs scripts

# 🔧 CHANGE SHELL (chsh)

## Command

```
chsh -s /bin/bash
```

## Change shell for specific user

```
sudo chsh -s /bin/zsh username
```

## Verify shell

```
echo $SHELL
grep $(whoami) /etc/passwd
```

## ⚙️ How chsh Works

* Updates user's login shell in `/etc/passwd`
* Requires valid shell from `/etc/shells`

## 🔥 Use Cases

### 1️⃣ Switch to better shell

```
chsh -s /usr/bin/zsh
```

👉 For better productivity (auto-suggestions, plugins)

### 2️⃣ Set restricted shell

```
sudo chsh -s /bin/rbash user1
```

👉 Limit user access (security)

### 3️⃣ Disable login (service user)

```
sudo chsh -s /usr/sbin/nologin serviceuser
```

👉 Prevent interactive login

### 4️⃣ Standardize environment (DevOps)

👉 Set same shell across servers

## ⚠️ Important Notes

* Shell must exist in `/etc/shells`
* Requires logout/login to apply
* Root can change for any user

```
chsh -s /bin/bash
```

# 🖥️ TMUX (TERMINAL MULTIPLEXER)

---

# 🔑 WHAT IS TMUX?

Run multiple terminals in one window + persistent sessions

---

# 🚀 BASIC TMUX COMMANDS

## Start tmux

```
tmux
```

## Create named session

```
tmux new -s dev
```

## List sessions

```
tmux ls
```

## Attach session

```
tmux attach -t dev
```

## Detach session

```
Ctrl + b → d
```

---

# 🪟 WINDOW COMMANDS

| Action          | Shortcut |
| --------------- | -------- |
| New window      | Ctrl+b c |
| Next window     | Ctrl+b n |
| Previous window | Ctrl+b p |
| Rename window   | Ctrl+b , |

---

# 🧩 PANE COMMANDS (Split Screen)

| Action           | Shortcut     |
| ---------------- | ------------ |
| Vertical split   | Ctrl+b %     |
| Horizontal split | Ctrl+b "     |
| Switch pane      | Ctrl+b arrow |
| Close pane       | exit         |

---

# 🔄 MOVE BETWEEN TERMINALS

## Switch panes

```
Ctrl+b + Arrow keys
```

## Switch windows

```
Ctrl+b + n / p
```

## Switch sessions

```
tmux switch -t session_name
```

---

# 🔥 ADVANCED TMUX COMMANDS

## Kill session

```
tmux kill-session -t dev
```

## Kill all

```
tmux kill-server
```

## Rename session

```
tmux rename-session -t old new
```
