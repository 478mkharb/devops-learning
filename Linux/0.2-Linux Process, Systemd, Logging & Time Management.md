## 📌 1. Process Management & Signals

### 🔹 1.1 kill with Signals

**Commands:**

```
kill -9 <PID>
kill -15 <PID>
kill -18 <PID>
kill -19 <PID>
```

| Signal | Name    | Behavior                      | Use Case         |
| ------ | ------- | ----------------------------- | ---------------- |
| -9     | SIGKILL | Force kill (cannot be caught) | Stuck process    |
| -15    | SIGTERM | Graceful termination          | Preferred method |
| -18    | SIGCONT | Resume stopped process        | Resume job       |
| -19    | SIGSTOP | Pause process                 | Debugging        |

**Example:**

```
kill -15 1234
```

---

### 🔹 1.2 pkill (Process by Name)

```
pkill nginx
pkill -u user1
pkill -f "python script.py"
```

**Explanation:** Kill processes using name/pattern instead of PID

---

### 🔹 1.3 pgrep

```
pgrep -l -u bob
```

**Explanation:** List processes of user `bob` with names

---

### 🔹 1.4 pstree

```
pstree
pstree -p
```

**Explanation:** Shows parent-child process hierarchy

## 📌 3. Systemd Service Management

### 🔹 3.1 List Services

```
systemctl list-unit-files --type service
```

**States:** enabled, disabled, static, masked

---

### 🔹 3.2 Service Status Checks

```
systemctl is-active sshd.service
systemctl is-enabled sshd.service
systemctl is-failed sshd.service
```

| Command    | Meaning        |
| ---------- | -------------- |
| is-active  | Running or not |
| is-enabled | Starts on boot |
| is-failed  | Failed state   |

## 📌 4. Logging (journalctl)

### 🔹 4.1 View Logs

```
journalctl
```

### 🔹 4.2 Follow Logs (Real-time)

```
journalctl -f
```

### 🔹 4.3 Logs for Service

```
journalctl -u sshd
```

### 🔹 4.4 Logs by Time

```
journalctl --since "1 hour ago"
journalctl --since "2026-01-01" --until "2026-01-02"
```

### 🔹 4.5 Logs by Boot

```
journalctl -b
journalctl -b -1
```

### 🔹 4.6 Priority Filtering

```
journalctl -p err
```

## 📌 5. Time & Timezone Management

### 🔹 5.1 View Current Time Settings

```
timedatectl
```

### 🔹 5.2 Set Timezone

```
timedatectl set-timezone Asia/Kolkata
```

### 🔹 5.3 List Timezones

```
timedatectl list-timezones
```

### 🔹 5.4 Enable NTP Sync

```
timedatectl set-ntp true
```

### 🔹 5.5 Set Manual Time

```
timedatectl set-time "2026-03-18 10:00:00"
```

## 📌 6. DevOps Real-World Use Cases 🔥

* Use `kill -15` before `-9` in production
* Use `pkill` in scripts for automation
* Debug services with `journalctl -u`
* Verify service health using `systemctl is-active`
* Always enable NTP in servers
