### 📌 WAF

#### Q1. What is AWS WAF?

**💡 Answer:** AWS WAF is a web application firewall for inspecting HTTP(S) requests. Web ACLs contain rules that can allow, block, count, challenge, or rate-limit requests based on request characteristics.
