# AMI

## Interview Questions & Answers

### Q1. What is an AMI?

**Answer:** An AMI is a reusable template used to launch EC2 instances. It defines the operating-system image and block-device mappings and can be copied or shared according to AWS rules.

### Q14. What should be removed or generalized before creating a reusable image?

**Answer:** Remove instance-specific secrets, credentials, temporary files, logs, and host-specific configuration. Generalize OS-specific identifiers where required and verify that the image contains only the approved baseline software and configuration.

---

### Q15. How can EC2 Image Builder automate image creation?

**Answer:** EC2 Image Builder automates the build, test, and distribution pipeline for machine images. It can apply build components, run validation tests, schedule image builds, and distribute approved AMIs to selected Regions.
