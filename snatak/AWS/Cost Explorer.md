# Cost Tag Reports via AWS Cost Explorer

## What is AWS Cost Explorer?

AWS Cost Explorer is a visualization and reporting tool that analyzes AWS spending using filters, tags, services, linked accounts, and time periods.

---

## Example Report

| Project | Monthly Cost |
|----------|-------------:|
| Employee API | $120 |
| Salary API | $80 |
| Attendance API | $60 |

---

## You Can Filter By

- Project
- Environment
- Team
- Service
- Region
- Account
- Tag
- Resource Type

---

## Benefits

- Visual cost analysis
- Daily/Monthly trends
- Forecast future spending
- Tag-based cost reporting
- Identify expensive resources

---

## DevOps Workflow

```text
Create AWS Resources
        │
        ▼
Apply Cost Allocation Tags
        │
        ▼
Enable Cost Allocation Tags
        │
        ▼
AWS Cost Explorer
        │
        ▼
Generate Tag-Based Reports
        │
        ▼
Identify High-Cost Projects
        │
        ▼
Optimize Cloud Costs
```

---

## DevOps Interview Answer

> AWS Cost Explorer provides graphical reports and analytics for AWS spending. By using Cost Allocation Tags, organizations can filter costs by project, team, application, or environment to improve cost visibility and optimization.
