# Frequently Asked Interview Questions

| Question | Answer |
|----------|--------|
| What are Cost Allocation Tags? | Key-value pairs used to categorize and track AWS resource costs. |
| Why are Cost Allocation Tags important? | They help track cloud spending by project, team, or environment. |
| What is an SCP? | An organization-level policy that defines the maximum permissions for AWS accounts. |
| Does an SCP grant permissions? | No. It only restricts or limits permissions. |
| What is AWS Budget? | A service that monitors spending against predefined budgets and sends alerts. |
| What is Cost Anomaly Detection? | An ML-based service that automatically detects unusual AWS spending. |
| What is AWS Cost Explorer? | A cost visualization and reporting service used to analyze AWS spending. |
| Can Cost Explorer use tags? | Yes. It can generate cost reports based on Cost Allocation Tags. |

# One-Line Revision

| Service | One-Line Definition |
|----------|---------------------|
| **Cost Allocation Tags** | Categorize AWS resources using key-value pairs for cost tracking. |
| **Service Control Policies (SCPs)** | Organization-level policies that restrict the maximum permissions available to AWS accounts. |
| **AWS Budgets** | Threshold-based alerts for planned AWS spending. |
| **Cost Anomaly Detection** | Machine learning service that detects unusual AWS spending automatically. |
| **AWS Cost Explorer** | Reporting and visualization tool for analyzing AWS costs and usage. |
